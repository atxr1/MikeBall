# MikeBall

A portrait football coaching sim for iPhone: you're the owner, general manager
and coach. Plain HTML/JS — no build step — played straight from GitHub Pages.

**Play:** https://atxr1.github.io/MikeBall/ (add it to your Home Screen for full
screen and offline play).
